Your data is stored in a Supabase Postgres table. Paste your credentials below — they're saved in localStorage on this device.

SQL to create the table
create table books (
  id uuid default gen_random_uuid() primary key,
  title text not null,
  author text,
  isbn text,
  cover_url text,
  status text default 'unread',
  created_at timestamptz default now()
);

Run this once in Supabase → SQL Editor if you haven't already.
